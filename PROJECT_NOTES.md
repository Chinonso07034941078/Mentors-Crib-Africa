# Mentors Crib Africa — Rebuilt JSX Handoff

This is a clean React 19 + JavaScript/JSX project using Vite and plain CSS. It intentionally does not use TypeScript, Tailwind, PostCSS, or the optional JSX-location plugin, avoiding the setup conflicts from the earlier package.

## Run locally with npm

```bash
npm install
npm run build
npm run dev
```

The Vite development server typically opens at `http://localhost:3000`.

## Included routes

Home, About, Mentors, Mentor Profile, Programs, Program Details, Resources, Resource Details, Community, Contact, Become a Mentor, Find a Mentor, and a styled Not Found route.

## Experience additions

The rebuild adds fuller editorial sections, responsive layouts, mentor search, form success state, mobile navigation, glass-morphism cards, image depth, animated orbital motifs, hover transitions, scroll-in reveal animations, reduced-motion support, richer resource/program/community content, and remote image URLs that work after extracting the ZIP locally.

## Visual direction

Editorial Transfer: near-white surfaces, primary blue `#0D089E`, electric cyan `#01E2FF`, Manrope display type, Inter body type, asymmetric editorial layouts, numbered chapters, transfer arrows/rules, glass layers, and human-centered imagery.
